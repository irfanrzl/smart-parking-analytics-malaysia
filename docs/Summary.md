# Project Summary

## Title
Analysis of Parking Demand Forecasting and Usage Pattern Clustering for
Smart Urban Decision Support in Malaysia

## Abstract
This project investigates parking demand across three anonymised Klang Valley
parking facilities (Site A, B, C) using 2025 transaction records. It addresses
three questions: *when* demand occurs (temporal pattern analysis), *how* each
site behaves (behavioural clustering), and *what* demand will be (forecasting).
The outputs are integrated into an interactive Streamlit dashboard to support
smart urban parking decisions.

## Objectives
1. **Temporal Pattern Analysis** — Characterise daily, weekly, and seasonal
   demand cycles through exploratory data analysis.
2. **Behavioural Clustering** — Group daily site behaviour using combined
   temporal and occupancy features to profile how each facility operates.
3. **Demand Forecasting** — Predict future demand and compare model behaviour
   across sites (LSTM, XGBoost, Linear Regression).

## Key Distinction
Objective 1 (temporal patterns) describes *when* demand happens across time.
Objective 2 (behavioural profiles) describes *how* a site operates across its
combined feature set. These are complementary, not overlapping.
